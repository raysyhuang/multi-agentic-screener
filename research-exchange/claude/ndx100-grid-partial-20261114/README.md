# 纳指100 动量网格 12×12×Top1–4×12 起始月（部分数据）（Claude，2026-11-14）

研究用途，不是投资建议。只写 `research-exchange/claude/`。

## 做法
- 6,912 条路径：回看 W=1–12 个月 × 持有 H=1–12 个月 × 买前 K=1–4 名 × 12 个起始月；每条跑 120 个月（2014-12 起，最晚到 2025-11）。
- 成分股：逐月历史名单（`../ndx100-partial-test-20261114/`）。
- 价格：只有约 84% 的成分月有价格（缺 49 只非标普500 股票，如 MELI、PDD、ASML、MRVL、ZM、PTON、APP、MSTR）。**所以这是部分回测，不是完整的纳指100 回测。**
- 引擎：月末近似（信号和成交同一个月末收盘、单边 25bp、只算价格、回撤按月末算）。不是精确引擎。
- 文件：`ndx_grid.py`、`paths_6912.csv`、`cells_576.csv`、`*_no_nvda.csv`、`run_stdout.txt`。

## 读法
1. **这十年在纳指上，几乎任何 W≥4 的参数都跑赢 QQQ**，不是某一个格子的偶然。只有 1–3 个月的短回看明显差。这点和标普500 不同（那里是一个尖峰）。
2. **靠的还是少数几只股票**：每个最好格子的持仓前五都是 NVDA、TSLA、MRNA、NFLX，加上 AMD/MU/ALGN。去掉 NVDA，整体中位数大约掉三分之一到四成（Top1 39.8%→23.3%）。
3. **不要选「最好的格子」**：Top1 的 W4/H2 是 576 格里挑出来的，起始月不同结果从 47.6% 到 82.8%；最高的单条路径（W4/H7/Top1，442 倍）是 6,912 条里的第一名，没有参考意义。可用的信息是「W4–W12 整片都高」。
4. **回撤被低估**：这里是月末回撤，Top1 多数格子 −50% 到 −70%；按日算会更深。
5. **证据的缺口**：
   - 只有一个十年，且是纳指最强的时期之一。没有 2000–2002（纳指跌约八成）和 2008。同类规则在标普500 的 2005–2015 是亏的。
   - 缺 16% 成分月，缺的多是高波动股票，补全后数字会变，方向不确定。
   - 没有样本外：参数、股票池、时期都是事后看的。

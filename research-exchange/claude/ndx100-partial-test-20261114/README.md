## 数据
- **成分股**：找到了。`ndx100_membership_month_end.csv` 由 GitHub 开源项目 jmccarrell/n100tickers（MIT，提交 16eaf93，覆盖 2007 年至今的逐次调整）导出，每个月末一行。`export_membership.py` 可重现。
- **价格**：没拿全。我的运行环境只能访问 GitHub 和包仓库，Yahoo/Stooq/FMP 网站都被拦；FMP 连接器只能逐只返回日线，量太大。所以价格只能用冻结包里已有的标普500 月末价。
- **覆盖率**：2015–2024 纳指100 的「成分股×月份」里约 84% 有价格。缺 49 只、1,937 个成分月，清单见 `missing_prices_request.csv`——主要是不在标普500 里的：MELI、PDD、ASML、MRVL、TEAM、ZM、DOCU、PTON、APP、MSTR、TTD、BIDU、JD 等。**其中不少正是动量规则会选中的股票，所以这只是部分回测。**
- 2007–2014 覆盖率只有 50%–77%，不测。

## 规则与引擎
帖子规则：月末按过去 6 个月「月度收益均值」排序，买前 3 等权，持有一个月。月末收盘成交，单边 25bp（另附零成本版本对照帖子口径），只算价格；并购标的在交割日前转现金。脚本 `ndx_partial_test.py`，输出 `ndx_partial_stdout.txt`、`ndx_partial_results.csv`。

## 读法
1. 在这十年、这个不完整的样本上，帖子规则的 Top3 确实大幅跑赢，去掉 NVDA 后仍然跑赢（靠 TSLA、MRNA、NFLX、AMD）。这和标普500 上「去掉 NVDA 就没了」不一样。
2. 但证据仍然薄：
   - 只有一个十年，而且是纳指科技股历史上最强的十年之一；没有 2000–2002、2008 的检验。同类规则在标普500 的 2005–2015 是 0.4% 年化、−74% 回撤。
   - 收益集中在 2020 年（+145%）和少数几只股票的少数几个月。
   - 缺 16% 的成分月，而且缺的偏偏是高波动的非标普股票（ZM、PTON、DOCU 在 2020–2021 很可能被选中，之后大跌）。补全后数字可能明显变化，方向不确定。
   - 越分散越弱：Top10 的 t 值只有 1.7。
3. 所以结论是「这十年在纳指上有效，原因是集中押中了几只超级股票」，不是「规则被验证」。

**唯一还未统一的呈现字段是已作废路径的调仓次数**：
- 对 417 条 `pick_not_tradable`，Queen 的答案表将 `n_rebalances_executed` 记为 0，因为整条路径被事后判作不可交易，并不保留有效成交台账。
- GPT 的审计器保留了在判断路径最终作废以前已经模拟过的 `attempted_rebalances`，因此这 417 条在该字段与 Queen 的 0 不同。
- 这不是选股、交易费用或净值差异；对于有效路径，调仓次数全部一致。

**验证范围声明：** `PROVISIONAL_C` 与 `CONDITIONAL` 的证据级别标签本次未独立计算；本次只核对了是否 UNKNOWN、失败记录以及可计算路径的资金、收益、回撤和成交笔数。当前工具环境实际运行的是 GPT 自写的 JavaScript 账本，提交的 Python 源码是独立可复现版本，但尚未在本工具环境执行，需要 Queen 在本地再运行一次确认。

## 尚未解决的真正风险

1. S&P 500 当时成分股及历史生效日仍为公开重建、需要独立权威核验。
2. 公司行动（分拆、换股、现金交易）、停牌退市与厂商调整价格仍须逐个核对；466条 UNKNOWN 没有替代处理或过度填补。
3. 2015年1月入场年冠在 12 个相位中表现突出，存在事后挑选的风险，需要独立样本外检验，不能只凭年冠的 60.54% CAGR 推导未来收益。
4. Top2/Top3 只在已核验后的同一规则中重置等权，并不意味着固定权重或免收续持调仓费。

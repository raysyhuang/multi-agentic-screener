# 纳指100 前三名：逐月持仓 + 「10% 止损、回到卖出价再买回」测试（Claude，2026-11-15）

研究用途，不是投资建议。只写 `research-exchange/claude/`。

规则：纳指100 成分股，按过去 6 个月平均月收益排名，买前 3 名等权，每月换；2014-12-31 → 2026-11-13；单边 25bp；只算价格。
选股用我的引擎 + 我的成分股导出 + Queen v1.1 月末价（与已互相核对的结果相同）。日线模拟用 Queen `raw/adj` 的 Massive 日线（开高低收），并套用她修正的分拆系数。

## 文件
- `holdings_by_month.csv`：143 个月的持仓、每只当月涨跌、组合收益、净值（原规则 / 加止损 / QQQ）。
- `index.html`：页面（净值、回撤、月收益、持仓变化图、逐月明细）。由 `page_template.html` + `page_data.json` 生成（`make_page_data.py`）。
- `stop_rebuy_sim.py`：日线模拟器；`stop_rebuy_results.csv`、`stop_rebuy_stdout.txt`：结果。

## 校验
- 不止损时，日线模拟的年化 37.9%、按日最大回撤 −49.7%，与 Queen 的 37.72%（按月数/12 计）/ −49.69% 一致；2007–2014 为 9.1%，与月末引擎一致。
- 逐只逐月收益与月末价对比：除 ESRX 2018-12（日线按最后交易日 −9.0%，月末引擎按 0%）外全部相同。

## 止损规则（Ray 的想法）
买入后在买入价 −10% 挂止损单（开盘跳空低于止损价按开盘价成交，否则按止损价）；卖出后在卖出价挂买回单（开盘高于则按开盘价，否则按卖出价）；买回价成为新的买入价；同一天不做来回。月底换仓时重新按新名单等权买入。

| 做法 | 2015–2026 年化 / 按日回撤 | 2007–2014 年化 / 按日回撤 |
|---|---|---|
| 不止损 | 37.9% / -49.7% | 9.1% / -54.1% |
| 止损 5% + 买回 | 21.2% / -64.7% | -7.1% / -65.9% |
| 止损 8% + 买回 | 23.0% / -53.3% | -0.2% / -62.5% |
| **止损 10% + 买回** | 23.2% / -56.7% | -0.2% / -62.1% |
| 止损 15% + 买回 | 25.1% / -58.1% | 2.4% / -62.5% |
| 止损 20% + 买回 | 28.5% / -55.1% | 5.2% / -59.2% |
| 止损 30% + 买回 | 34.3% / -53.9% | 6.7% / -55.7% |
| 止损 10% + 买回，只看收盘价 | 31.4% / -52.8% | 2.4% / -63.2% |
| 止损 10% + 买回，跨月不重置 | 19.6% / -64.7% | -0.2% / -62.1% |
| 止损 10%，不买回，等月底 | 25.1% / -47.8% | 1.2% / -48.5% |
| 止损 20%，不买回，等月底 | 26.5% / -63.4% | 4.7% / -54.0% |
（精确数字以 `stop_rebuy_results.csv` 为准。）

结论：两段时间里，止损 + 买回都同时降低了收益、加深了回撤。2015–2026 共止损 219 次、买回 199 次，其中 45 次跳空成交；平均每次止损实亏 10.6%，买回价平均比卖出价高 2.2%。止损线越宽越接近不止损。唯一回撤略浅的是「止损 10% 不买回」（−47.8% 对 −49.7%），代价是年化少 13 个点。

## 局限
日线只有拆股调整；挂单模型假设止损价/买回价能精确成交（跳空除外），未计滑点；同日不做来回；现金无利息；8 个早期持仓只有月度数据（不参与止损）。

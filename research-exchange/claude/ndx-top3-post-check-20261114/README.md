# 小红书「纳指100动量策略」帖子核对（Claude，2026-11-14）

研究用途，不是投资建议。只写 `research-exchange/claude/`。

帖子规则：每月底在纳指100成分股里，按过去 6 个月「月度收益均值」排序，买前 3 名等权，持有一个月；不计佣金、滑点、税。

## 1. 帖子里的数字对不对（FMP 收盘价，`fmp_spot_check.csv`）
全部对得上：5 月（4/30 收盘 → 5/29 收盘）SNDK +54.58%、WDC +22.25%、INTC +21.38%、QQQ +10.57%，组合 +32.74%。
注意它假设按 4/30 信号日的收盘价成交。

帖子给出的 6 月持仓（SNDK、MU、INTC），5/29 → 6/30：+34.15%、+18.88%、+21.76%，平均 +24.9%；QQQ −0.26%。
7/1 当天三只分别 −10.6%、−10.6%、−9.0%。之后的月份没有跟踪（需要每月的成分股和排名）。

## 2. 这条规则长期怎么样
**纳指100 没法在这里严格回测**：没有逐月的历史成分股名单，用今天的名单回测会有幸存者偏差。
替代做法：同一条规则放到我们已有的标普500 数据上跑（`sp500_analog.py`，月末近似引擎，单边 25bp，只算价格）。这是类比，不是纳指结果。

| | 年化 | 最大回撤（月末） | 最差年 | 相对等权基准 t 值 |
|---|---|---|---|---|
| 2015–2025 Top3 | 13.9% | −39% | −28% | 1.1 |
| 2015–2025 Top3 去掉 NVDA | 4.1% | −39% | −28% | 0.0 |
| 2005–2015 Top3 | 0.4% | −74% | −50% | −0.5 |
| 等权基准 | 7.8% / 7.6% | −27% / −54% | | |

- 年换手约 600%+。
- 单月最好 +20%，最差 −37%（2015–2025）。
- 「月度收益均值」是算术平均，会偏向波动最大的股票。

## 3. 读法
- 帖子数字是真的，但只是 1–2 个月，且三只都是同一个存储/半导体主题（SNDK、WDC、MU、STX 都在前五）——这是一次行业押注，不是三只分散的股票。
- 同样的规则在标普500 上：一个十年靠 NVDA，另一个十年基本不赚钱且回撤 −74%。
- 一两个月的 +30% 不能说明规则有效，也不能说明无效。

# 能不能保住收益、避开回撤？几种常见做法的测试（Claude，2026-11-14）

研究用途，不是投资建议。只写 `research-exchange/claude/`。

基准：纳指100 帖子规则（6 个月平均月收益，前 3 名，每月换，单边 25bp，只算价格），Queen v1.1 价格，我的引擎和成分股名单。
叠加规则都在信号月末决定仓位（不偷看未来），现金收益按 0，调整仓位按变动额收 25bp（近似）。回撤是月末口径，按日会更深。
脚本 `dd_overlays.py`，结果 `dd_overlays_stdout.txt`、`dd_overlays_results.csv`。

| 做法 | 2007–2014 年化 / 回撤 | 2015–2026 年化 / 回撤 |
|---|---|---|
| QQQ 买入持有 | 11.5% / −50% | 17.2% / −33% |
| Top3 原规则 | 9.1% / −42% | 38.3% / −46% |
| Top3 + QQQ 跌破 10 月均线就空仓 | 6.2% / −38% | 20.8% / −46% |
| Top3 + QQQ 过去 12 个月为负就空仓 | 5.8% / −41% | 33.1% / −46% |
| Top3 半仓（另一半现金） | 5.3% / −23% | 20.1% / −24% |
| Top3 一半 + QQQ 一半 | 11.0% / −44% | 29.0% / −38% |
| Top3 波动目标 30% | 8.6% / −42% | 34.6% / −42% |
| Top3 自身回撤超 25% 就退出 | 0.9% / −49% | 33.6% / −37% |
| Top10 原规则 | 10.5% / −62% | 20.6% / −41% |
| Top10 + QQQ 跌破 10 月均线就空仓 | 11.9% / −36% | 12.4% / −41% |
| QQQ + 跌破 10 月均线就空仓 | 7.9% / −27% | 11.8% / −21% |

## 读法
1. **没有一种做法在两段时间里都「收益不降、回撤变小」。**
2. 大盘择时（均线、12 个月动量）对 Top3 基本没用：Top3 的大回撤多数发生在大盘还在均线之上的时候，是个股自己崩，不是大盘崩。2015–2026 回撤一点没少，收益少了很多。
3. 唯一稳定降低回撤的是**少放一点**（半仓）：回撤减半，收益也大致减半。这是降杠杆，不是免费的。
4. 「自身回撤止损」「波动目标」在 2015–2026 略有改善，在 2007–2014 没用甚至更糟（0.9%），不稳定。
5. 这里只试了 8 种叠加，每种只有一组参数；再多试几十种，总能找到一种「看起来两段都好」的，那是挑出来的，不是证据。

## 局限
月度数据、月末回撤；现金无利息；叠加规则的成本是近似；只有纳指一个市场、两段时间。
